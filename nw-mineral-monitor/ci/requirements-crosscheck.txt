# Reference implementations the geomodel format tests validate against.  These
# are NOT runtime dependencies: pipelines/geomodel is pure standard library, and
# that is the point -- every reader and writer here is checked against somebody
# else's implementation of the same format.
#
#   pip install -r ci/requirements-crosscheck.txt
#   python3 tools/fetch_gm_refs.py
#
# NumPy stays below 2 for the same reason as ci/requirements.txt (the reviewed
# Shapely 2.0.3 wheel targets the NumPy 1.x ABI), and every pin below resolves
# against it.  The reference OMF v0.9 writer (omf 1.0.1) is deliberately absent:
# it pins old properties/vectormath releases, so tools/fetch_gm_refs.py gives it
# a venv of its own instead of letting it near this interpreter.
